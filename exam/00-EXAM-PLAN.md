# Екзамен: PostgreSQL без ORM (senior-рівень)

Проводить Claude Code після проходження всіх фаз і закриття checkpoint-ів у `notes/`.

Мета — не «здати», а знайти діри до реальної співбесіди.

---

## Формат

Три частини, окремі сесії (не за один день):

### Частина A — усна теорія (60–90 хв)
Я ставлю 25 питань із банку (`plan/13-interview-prep.md` §12.2) + імпровізовані уточнення («а чому?», «а що як 10x даних?»). Ти відповідаєш текстом у `exam/A-answers.md`, я оцінюю кожну:
- **2** — повна відповідь + компроміси + приклад;
- **1** — суть вірна, бракує глибини/нюансу;
- **0** — невірно або «плаваю».

Прохідний бал: **≥ 40 із 50** і жодної **0** у розділах «Транзакції», «Індекси й плани», «Internals».

### Частина B — практика на `shop` (2–3 год)
`exam/B-tasks.sql` — 12 задач, які я видаю по одній:
1. 3 задачі на запити середньої складності (JOIN + агрегація + віконні).
2. 2 задачі «ось повільний запит + його план — поясни й прискор» (треба показати план до/після, назвати причину, обґрунтувати фікс).
3. 2 задачі на моделювання («додай сутність X, обмеження, індекси, покажи міграцію без даунтайму»).
4. 2 задачі на конкурентність (написати коректний сценарій зі `SELECT ... FOR UPDATE` / `ON CONFLICT`; пояснити поведінку на Repeatable Read).
5. 1 задача на JSONB / FTS.
6. 1 задача на партиціонування (план + partition pruning).
7. 1 «пастка» (запит, що виглядає правильним, але має баг — `NOT IN`+`NULL`, `BETWEEN` на межі, роздута `sum`, функція на стовпці). Знайти й виправити.

Оцінка кожної: коректність результату + якість плану + пояснення. Прохідний: **9 із 12**, і обов'язково пройдені B2 (плани) та B4 (конкурентність).

### Частина C — системний дизайн (45 хв, усно/текстом)
Один сценарій із `plan/13-interview-prep.md` §12.3 (я обираю). Ти за 45 хв даєш: схему, індекси, 3 ключові запити з очікуваним планом, компроміси, «що зламається на масштабі». Я пресингую уточненнями.
Прохідний: рішення тримає критику, названо ≥ 3 усвідомлені компроміси.

## Підсумок

Після трьох частин — файл `exam/RESULT.md`:
- бал по кожній частині;
- **список тем, де просів** (конкретні підплани для повторного проходу);
- 5–7 питань, які варто ще раз проговорити вголос напередодні співбесіди;
- рішення: `PASS` (готовий іти на співбесіди senior-рівня) / `RETAKE через 2 тижні по темах [...]`.

Після `PASS` → `notes/cv-bullets.md` (я збираю формулювання для резюме з усього пройденого).
